# Polynomial Factorization

Do you have a math test tomorrow and want to play Geometry Dash instead? Well look no further!
This mod will quiz you with <cr>rage inducing</c> polynomials that <cp>YOU</c> need to solve.

Questions include:
- Quadratics
- Cubics
- Quartics (Why would you torture yourself like this?)



## Planned Features:
- Saving questions even if you close the game
- Quintics :skull:
